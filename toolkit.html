Install the toolkit

Fedora · Copr · dnf

The LGL Toolkit.

A collection of small desktop apps for Fedora, all in one Copr repository. Enable the repo once, install only what you need, and let normal system updates keep them current.

Fedora 44 Fedora 45 Rawhide x86_64 + aarch64

Step one

Enable the repository

This adds the Copr repo and imports its signing key. You only need to do it once.

sudo dnf copr enable linuxgamerlife/lgl-toolkit
Run the command above in a terminal and confirm when DNF asks.
Install an app from the list below with sudo dnf install <package>.
Keep it updated: sudo dnf upgrade picks up new releases like any other package.

Read before running. These commands change system packages. Read them, understand them, and use them at your own risk.
