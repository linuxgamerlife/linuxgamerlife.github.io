# Self-hosted fonts

These files are the only web fonts used by the site. No requests are made to
Google Fonts.

- **Inter** by The Inter Project Authors, SIL Open Font License 1.1.
  Latin and Latin Extended subsets, variable weight 100–900.
  Source: https://github.com/rsms/inter
- **JetBrains Mono** by JetBrains, SIL Open Font License 1.1.
  Latin and Latin Extended subsets, variable weight 100–800.
  Source: https://github.com/JetBrains/JetBrainsMono

The Latin files are preloaded in each page. The Latin Extended files load only
when a page needs those characters.

Licence texts are in `LICENSE-Inter.txt` and `LICENSE-JetBrainsMono.txt`.
